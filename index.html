「Webコンテンツ作成」の成果

本テーマについて

私は、HTMLを使ってWebページがどのように作られているのかを学び、自分でも簡単なWebページを作れるようになりたいと思った。また、文字の装飾やリンクの貼り方などの基本的な技術を身に付け、見やすいWebコンテンツを作れるようになりたいと考えた。

プロジェクト課題について

今回のプロジェクト課題では、JavaScriptを使ってAPIからデータを取得し、検索結果を画面に表示するプログラムを作成した。 最初はAjax通信やDOM操作などを理解し、検索結果が重複しないように前回の表示を削除する処理を作成するのに苦労したが、処理をコンソールで一つずつ確認しながら修正することで完成させることができた。 また、ジャンル一覧を表示する工夫も行った。この課題を通して、Webページを動的に操作する仕組みやWebページのレイアウト方法などについて自分が理解していることの総復習をすることができ、さらに知識の定着につながった。

数当てゲーム

今回の課題では、JavaScriptを使って数当てゲームを作成した。 HTMLで数字を入力するためのテキストボックスと判定ボタンを設置し、JavaScriptで1〜10のランダムな数を正解として設定した。 ユーザが入力した数字と比較して判定をさせ、回答するたびに予想回数をカウントして画面に表示した。 予想が外れた場合には、ヒントとして入力した数字より正解の数が大きいか小さいかを表示した。 3回以内に正解すると成功メッセージを表示させ、3回間違えた場合には正解の数を表示するようにした。 ゲーム終了後にもう一度ボタンを押した場合には、すでにゲームが終了しているという文を表示するプログラムを追加した。 実際に動作を確認しながらプログラムを作成し、条件分岐やイベント処理について深く学ぶことができた。

各授業回の学習事項

第１回 WWW と HTML

HTML文書の作成の仕方と、文書内での文章の文字を太くしたり、段落を変えたりするなどの編集方法や、リンクの貼り方について学んだ。また、タグを用いてWebページの見た目や構造を整える方法についての基礎知識を学ぶことができた。

演習1-4:HTMLのさまざまな要素

第２回 CSS による Web ページの装飾

CSSを用いてWebページのデザインを編集した。文字の大きさや色、余白を調整した。自分が利用者だったら使いやすいか、見やすいかを考えながら、見やすさを意識し、また、全体のバランスにも意識しながら工夫を重ねてレイアウトを編集した。

演習2-3: ウェブブラウザ説明ページの装飾

第３回 JavaScript の基本

JavaScriptの構文とhtmlにJavaScriptを追加する方法とコンソールに出力するプログラムの作り方を学んだ。JavaとJavaScriptではプログラムが少し似ているが違う点があり、Javaの方が慣れているからかJavaScriptのプログラムの方がプログラム自体は短いがその分、分かりづらく感じた。

演習3-6: オブジェクトの参照

第４回 DOM と JavaScript

イベント処理を学んだ。それに伴ってinput要素のさまざまなtype属性にも触れた。開発ツールで操作した際にうまく実行するかを確認しながらJavaScriptを編集した。コンソールで表示させれるかだけでなく、ページに実際に表示されるかをよく確認し、ページに表示するのに要素が足りない場合はhtmlに要素を追加した。

演習:4-10足し算

第５回 イベント処理

新たにJavascriptでの構文を学んだ。実際に使ってみると慣れていないからかどっちがどっちかわからなくなることがあったので講義資料の同じところを繰り返し見直した。それでも怪しいのでプログラムを書くとき自分で書いてて怪しいと思ったら自分の記憶には頼らず、ありがたく資料を活用させていただけることに感謝すると同時に自分の記憶力に虚しさを覚えた。

演習:5-7:DOMの演習その2

第６回 通信処理とプロジェクト課題のまとめ

APIを利用してデータを取得し、Webページに表示する方法を学んだ。Ajax通信やDOM操作は難しかったが、実際にプログラムを動かしながら理解を深めることができた。今後も少しずつ慣れていきたいと思った。

工夫点、苦心点、強調点、感想

今までの授業を通して、HTML、CSS、JavaScriptを使ったWebページの作成方法を学ぶことができた。授業を受ける前はWebページがどのように作られているのかほとんど知らなかったが、実際に自分でプログラムを書きながら課題に取り組むことで、少しずつ仕組みを理解できるようになった。 最初はHTMLやCSSの記述ミスで表示が崩れたり、JavaScriptでエラーが発生したりすることが多かった。 しかし、そのたびに講義資料やコンソールを確認しながら修正を繰り返したことで、自分で原因を考えて解決する力が身に付いたと感じている。 特に工夫したのは最後のプロジェクト課題である。検索結果を見やすくするため、CSSでボタンや背景、文字のデザインを整えた。 また、検索結果はお店の名前だけを表示し、クリックすると詳細を確認できるようにdetails要素とsummary要素を利用した。 さらに、ジャンルをプルダウンメニューから選択して検索できるようにし、利用しやすいページになるよう工夫した。 一方で最も苦労したのもプロジェクト課題である。ジャンルを選択しても正しい検索結果が表示されなかったり、検索を繰り返すと前回の結果が残ってしまったりする問題があった。 原因を調べながら何度も修正を行い、最終的には思い通りに動作するようになった。この経験を通して、動作確認を繰り返しながら一つずつ問題を解決することの大切さを学んだ。 また、数当てゲームの課題では、条件分岐やイベント処理について理解を深めることができた。ランダムな数字の生成や入力値との比較、ヒントの表示などを実装し、処理の流れを考えながらプログラムを作成する力を身に付けることができた。 授業全体を振り返ると、最初は難しく感じることも多かったが、毎回の課題を通して少しずつ知識と技術を身に付けることができた。 特にプロジェクト課題では、HTML、CSS、JavaScriptを組み合わせて一つのWebページを完成させることができ、大きな達成感を得られた。 今回学んだ内容はまだ基礎ではあるが、今後も復習を続け、さらに実用的なWebページやWebアプリケーションを作れるようになりたい。
