「Webコンテンツ作成」の成果

本テーマについて

私は、HTMLを使ってWebページがどのように作られているのかを学び、自分でも簡単なWebページを作れるようになりたいと思った。また、文字の装飾やリンクの貼り方などの基本的な技術を身に付け、見やすいWebコンテンツを作れるようになりたいと考えた。

プロジェクト課題について

今回のプロジェクト課題では、JavaScriptを使ってAPIからデータを取得し、検索結果を画面に表示するプログラムを作成した。 最初はAjax通信やDOM操作などを理解し、検索結果が重複しないように前回の表示を削除する処理を作成するのに苦労したが、処理をコンソールで一つずつ確認しながら修正することで完成させることができた。 また、ジャンル一覧を表示する工夫も行った。この課題を通して、Webページを動的に操作する仕組みやWebページのレイアウト方法などについて自分が理解していることの総復習をすることができ、さらに知識の定着につながった。

数当てゲーム

今回の課題では、JavaScriptを使って数当てゲームを作成した。 HTMLで数字を入力するためのテキストボックスと判定ボタンを設置し、JavaScriptで1〜10のランダムな数を正解として設定した。 ユーザが入力した数字と比較して判定をさせ、回答するたびに予想回数をカウントして画面に表示した。 予想が外れた場合には、ヒントとして入力した数字より正解の数が大きいか小さいかを表示した。 3回以内に正解すると成功メッセージを表示させ、3回間違えた場合には正解の数を表示するようにした。 ゲーム終了後にもう一度ボタンを押した場合には、すでにゲームが終了しているという文を表示するプログラムを追加した。 実際に動作を確認しながらプログラムを作成し、条件分岐やイベント処理について深く学ぶことができた。

第１回 WWW と HTML

HTML文書の作成の仕方と、文書内での文章の文字を太くしたり、段落を変えたりするなどの編集方法や、リンクの貼り方について学んだ。また、タグを用いてWebページの見た目や構造を整える方法についての基礎知識を学ぶことができた。

第２回 CSS による Web ページの装飾

CSSを用いてWebページのデザインを編集した。文字の大きさや色、余白を調整した。自分が利用者だったら使いやすいか、見やすいかを考えながら、見やすさを意識し、また、全体のバランスにも意識しながら工夫を重ねてレイアウトを編集した。

演習2-3: ウェブブラウザ説明ページの装飾

第３回 JavaScript の基本

JavaScriptの構文とhtmlにJavaScriptを追加する方法とコンソールに出力するプログラムの作り方を学んだ。JavaとJavaScriptではプログラムが少し似ているが違う点があり、Javaの方が慣れているからかJavaScriptのプログラムの方がプログラム自体は短いがその分、分かりづらく感じた。

演習3-6: オブジェクトの参照

第４回 DOM と JavaScript

イベント処理を学んだ。それに伴ってinput要素のさまざまなtype属性にも触れた。開発ツールで操作した際にうまく実行するかを確認しながらJavaScriptを編集した。コンソールで表示させれるかだけでなく、ページに実際に表示されるかをよく確認し、ページに表示するのに要素が足りない場合はhtmlに要素を追加した。

工夫点、苦心点、強調点、感想

今までの授業を通して、HTML、CSS、JavaScriptを使ったWebページの作成方法について学ぶことができた。授業を受ける前は、Webページがどのように作られているのかあまり知らなかったが、実際に自分でプログラムを書いて課題を進めていく中で、少しずつ仕組みを理解できるようになった。 最初はHTMLのタグの使い方やCSSの書き方も慣れておらず、少し間違えるだけで思ったような表示にならなかったり、JavaScriptではエラーが出て動かなかったりすることも多かった。 しかし、そのたびに講義資料を見返したり、コンソールで確認したりしながら修正を繰り返したことで、以前よりも自分で原因を考えながらプログラムを書けるようになったと感じている。 一番工夫した点は、最後のプロジェクト課題で検索結果を見やすく表示するようにしたことである。ただ検索結果を表示するだけでは情報が多く見づらいと思ったため、CSSを使ってデザインを整えた。検索ボタンやジャンルを選択するプルダウンメニューの色や大きさを調整し、背景色や文字のデザインも工夫して、全体的に見やすいページになるよう意識した。 また、検索結果はすべてを一度に表示するのではなく、お店の名前だけを表示し、クリックすると詳細が表示されるようにした。これにはdetails要素とsummary要素を使用し、講義資料を参考にしながら実装した。利用する人が必要な情報だけを確認できるため、画面がすっきりして見やすくなったと思う。 ジャンルを選択する部分についても、select要素とoption要素を講義資料を参考にして作成し、ボタンを押すだけで検索できるように工夫した。 一番苦労した点もプロジェクト課題である。特にジャンルをプルダウンメニューから選択して検索する部分では、選択した値を正しく取得できず、思ったジャンルの検索結果が表示されないことが何度もあった。 講義資料を見返しながら原因を探し、コンソールで値を確認して修正を繰り返した。また、検索結果をdetails要素とsummary要素を使って開閉できるようにする処理も難しかった。JavaScriptで要素を一つずつ作成して追加していく流れを理解するまで時間がかかり、最初は思ったような表示にならなかった。 しかし、何度も動作確認をしながら修正したことで、最終的には自分が考えていた形で表示できるようになった。さらに、検索ボタンを何度も押すと前回の検索結果が残ってしまったため、以前の検索結果を削除する処理も追加した。 この処理も最初はうまく動かなかったが、一つずつ確認しながら修正し、検索するたびに新しい結果だけが表示されるようにすることができた。 数当てゲームの課題も印象に残っている。ランダムな数字を生成し、入力された数字と比較して判定を行うだけでなく、予想回数を数えたり、ヒントを表示したり、ゲーム終了後のメッセージを表示したりするなど、条件分岐やイベント処理について理解を深めることができた。 思ったように動かないこともあったが、実際に何度も遊びながら修正を繰り返したことで、プログラムを少しずつ完成させることができた。この課題では、処理の流れを考えながらプログラムを書くことの大切さを学ぶことができた。 授業全体を振り返ると、最初は分からないことばかりで難しいと感じることも多かったが、毎回の課題を通して少しずつ知識を身に付けることができたと思う。 特に最後のプロジェクト課題では、HTML、CSS、JavaScriptを組み合わせて一つのWebページを完成させることができ、これまで学んだ内容を総復習する良い機会になった。エラーが出るたびに時間がかかり大変だと感じることもあったが、自分で原因を見つけて修正し、思い通りに動いたときにはとても達成感があった。 今回学んだ内容はまだ基礎ではあるが、これからもプログラミングを学ぶ上で役立つ知識だと思うので、忘れないように復習し、さらにいろいろなWebページやWebアプリケーションが作れるようになりたいと思う。
